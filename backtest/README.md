# backtest/: which file is what

**Current results (start here)**
| File | What it is |
|---|---|
| `V3_PROTOCOL.md` | the v3 rules (written before the results), all v3 results, and the decision |
| `results_v3.csv` | every replay forecast's score: baseline, v1, v2, v3 (`ensemble`) on identical forecasts |
| `vs_cdc_v3.md` | Sentinel vs the CDC's real baseline and ensemble, same forecasts |
| `leaderboard_official.md` | rank among all hub teams the CDC's way (pairwise, counts and log counts) |
| `all53.md` | all 53 places (incl. the US, DC, Puerto Rico) in the exact live setup, vs the CDC baseline and ensemble |
| `leaderboard_v3.md` | simpler rank (ratio of mean scores), counts only |
| `v3_results.csv` | the v3 experiment table |
| `rate_change_eval.csv` | the trend-target check (`rate_change_eval.py`) |
| `recent_check.md` | July-September 2026: forecasts vs what happened, in patients (`recent_check.py`) |

**v2 (kept for the record; v2's 2025-26 numbers are Sentinel's only blind result)**
`results_v2.csv`, `vs_cdc_v2.md`, `leaderboard_v2.md`: v2 as first scored, before the week-53 calendar fix
(`results_v3.csv` holds v2 re-run with the fix: total WIS +0.10%, +0.07%, +0.01% by season).

**v1 (the first design)**
`results_scores_realtime.csv`, `vs_cdc_realtime.md`, `summary_realtime.md`, `leaderboard.md` (real-time replay),
`results_scores.csv`, `vs_cdc.md`, `summary.md` (replay with corrected data, too optimistic)

**Code**
| File | What it does |
|---|---|
| `harness.py` | replays past weeks with the data exactly as published; scoring and the bootstrap |
| `run_v2.py` | official v2 replay (ER visits as really published) |
| `member_cache.py`, `exp_gbq.py`, `exp_v3.py` | caches of every model family's forecasts, and the v3 experiments |
| `compare_cdc.py`, `leaderboard.py`, `leaderboard_official.py` | comparisons with the CDC and the hub teams |
| `eval_all53.py` | scores the all-53-places replay (`exp_v3.py --produce-all`) |
| `check_engine_vs_replay.py` | runs the engine end-to-end on replay weeks and checks it equals the replay, bit for bit |
| `rate_change_eval.py` | the trend target, replayed and compared with the hub teams |
| `recent_check.py` | the last three months, in numbers of patients |
| `score_sealed.py` | scores the sealed forecasts in `submission/sealed/` once the truth is out |
| `experiments.py`, `exp2.py`, `run_backtest.py` | v1 and v2-era experiments and the v1 replay |
| `wis.py` | the CDC's scoring rule (weighted interval score) |
| `cache/` | per-week forecasts of each model family (regenerated by the scripts above) |
